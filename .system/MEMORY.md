# Memória durável da vault

Use este arquivo para decisões que continuam válidas entre sessões, como
posicionamento aprovado, padrões de marca, projetos ativos e processos já
validados.

## Estado inicial

- Esta é uma instalação inicial do Otear OS.
- Não há integrações externas configuradas por padrão.
- O catálogo e o roteador indicam o caminho de cada capacidade; disponibilidade
  real depende dos pré-requisitos descritos em cada item.

## Registro de decisões

Adicione novas decisões com data, contexto e responsável.
