# Atalhos de Pedido do Otear OS

Estes são comandos em linguagem natural para usar no chat do Otear OS. Não é necessário conhecer o nome de agentes, skills ou squads.

## Antes de Pedir

Sempre que puder, inclua negócio, público, oferta, objetivo, canal e referências. Se faltar algo importante, o Otear OS deve perguntar antes de produzir.

## Conteúdo, Copy e Marca

```text
Otear OS, crie um calendário de 30 dias de conteúdo para [marca].
Otear OS, escreva a copy desta oferta para [público] com foco em [objetivo].
Otear OS, crie um carrossel de Instagram sobre [tema].
Otear OS, construa o posicionamento e tom de voz da minha marca.
Otear OS, crie um roteiro de vídeo de [duração] sobre [tema].
```

## Sites, SEO e Sistemas

```text
Otear OS, crie uma landing page para [oferta] voltada a [público].
Otear OS, audite o SEO de [URL] e entregue uma lista priorizada de melhorias.
Otear OS, transforme este processo em uma automação: [descreva o processo].
Otear OS, crie um aplicativo simples para resolver [problema].
```

## Tráfego, Anúncios e Vendas

```text
Otear OS, monte um plano de tráfego pago para [oferta], com verba de [valor] e objetivo [leads/vendas/mensagens].
Otear OS, crie 5 variações de anúncio para [oferta] no canal [Meta/Google].
Otear OS, analise estes dados de campanha e diga o que pausar, testar e escalar: [dados].
Otear OS, gere um relatório de tráfego claro para meu cliente usando estes dados: [dados].
```

## Prospecção e Perfil

```text
Otear OS, encontre o perfil ideal de cliente para [oferta] em [cidade/nicho].
Otear OS, analise este perfil e proponha um plano de conteúdo: [@perfil ou URL].
Otear OS, crie uma sequência de abordagem para estes leads: [contexto].
```

## Comandos de Segurança

Acrescente uma destas frases quando necessário:

```text
Entregue somente um plano; não execute nenhuma ação externa.
Mostre um resumo para minha aprovação antes de publicar ou gastar verba.
Explique em linguagem simples, passo a passo.
```

## Quando a Resposta Estiver Genérica

```text
Refaça considerando este contexto: [contexto].
Use tom [tom] e siga estas referências: [referências].
Antes de continuar, faça-me as 3 perguntas mais importantes.
```
