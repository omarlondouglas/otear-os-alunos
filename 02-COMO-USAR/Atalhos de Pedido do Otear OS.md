# Atalhos de Pedido do Otear OS

Estes sao comandos em linguagem natural para usar no chat do Otear OS. Nao e necessario conhecer o nome de agentes, skills ou squads.

## Antes de Pedir

Sempre que puder, inclua negocio, publico, oferta, objetivo, canal e referencias. Se faltar algo importante, o Otear OS deve perguntar antes de produzir.

## Conteudo, Copy e Marca

```text
Otear OS, crie um calendario de 30 dias de conteudo para [marca].
Otear OS, escreva a copy desta oferta para [publico] com foco em [objetivo].
Otear OS, crie um carrossel de Instagram sobre [tema].
Otear OS, construa o posicionamento e tom de voz da minha marca.
Otear OS, crie um roteiro de video de [duracao] sobre [tema].
```

## Sites, SEO e Sistemas

```text
Otear OS, crie uma landing page para [oferta] voltada a [publico].
Otear OS, audite o SEO de [URL] e entregue uma lista priorizada de melhorias.
Otear OS, transforme este processo em uma automacao: [descreva o processo].
Otear OS, crie um aplicativo simples para resolver [problema].
```

## Trafego, Anuncios e Vendas

```text
Otear OS, monte um plano de trafego pago para [oferta], com verba de [valor] e objetivo [leads/vendas/mensagens].
Otear OS, crie 5 variacoes de anuncio para [oferta] no canal [Meta/Google].
Otear OS, analise estes dados de campanha e diga o que pausar, testar e escalar: [dados].
Otear OS, gere um relatorio de trafego claro para meu cliente usando estes dados: [dados].
```

## Prospeccao e Perfil

```text
Otear OS, encontre o perfil ideal de cliente para [oferta] em [cidade/nicho].
Otear OS, analise este perfil e proponha um plano de conteudo: [@perfil ou URL].
Otear OS, crie uma sequencia de abordagem para estes leads: [contexto].
```

## Comandos de Seguranca

Acrescente uma destas frases quando necessario:

```text
Entregue somente um plano; nao execute nenhuma acao externa.
Mostre um resumo para minha aprovacao antes de publicar ou gastar verba.
Explique em linguagem simples, passo a passo.
```

## Quando a Resposta Estiver Generica

```text
Refaca considerando este contexto: [contexto].
Use tom [tom] e siga estas referencias: [referencias].
Antes de continuar, me faca as 3 perguntas mais importantes.
```
