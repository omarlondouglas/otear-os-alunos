# START AQUI

Bem-vindo ao Otear OS.

Use esta vault no Obsidian para entender, operar e adaptar o sistema. O Otear OS é a sua interface de trabalho; os motores técnicos funcionam nos bastidores.

Você aprenderá a usar o Hermes junto com esta vault. Ao longo das conversas, registre preferências, decisões e processos aprovados para que o sistema conheça melhor o seu negócio e melhore continuamente com o seu contexto.
