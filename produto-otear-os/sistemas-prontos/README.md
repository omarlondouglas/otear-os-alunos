# Sistemas Prontos

Esta pasta contem sistemas completos que acompanham o Otear OS.

## Otear Prospeccao

```text
produto-otear-os/sistemas-prontos/otear-prospeccao
```

Inclui:

- `squads/prospect-pro`: agente/squad tecnico de prospeccao;
- `apps/o-tear-prospeccao`: aplicacao visual/CRM de prospeccao;
- arquivos `.env.example` para configuracao;
- pastas vazias para leads, enriquecimentos e relatorios.

Nao inclui `.env` real, ambiente virtual, logs, cookies, screenshots antigas nem leads historicos.
