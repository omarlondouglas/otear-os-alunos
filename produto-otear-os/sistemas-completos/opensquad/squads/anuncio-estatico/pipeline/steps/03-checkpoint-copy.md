# Checkpoint: Aprovação da Copy

## Instruções

Revise a copy criada pelo copywriter antes de prosseguir para o design visual.

Verifique:
- A headline é impactante e para o scroll?
- O corpo é claro e direto?
- O CTA é acionável?
- O tom de voz está adequado?

### Opções
1. ✅ Aprovar copy e seguir para design
2. ✏️ Solicitar ajustes na copy
3. 🔄 Refazer com outro ângulo/tom
