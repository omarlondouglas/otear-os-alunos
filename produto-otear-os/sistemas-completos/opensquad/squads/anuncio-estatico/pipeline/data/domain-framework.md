# Domain Framework — Anúncio Estático (Meta Ads)

## Processo Operacional

### 1. Briefing e Diagnóstico
- Identificar produto/oferta a ser anunciado
- Definir público-alvo e nível de consciência (Schwartz)
- Escolher o ângulo emocional principal (medo, oportunidade, curiosidade, autoridade, pertencimento)
- Definir o objetivo do anúncio (clique, cadastro, venda direta)

### 2. Criação da Copy
- Escrever 3 opções de headline usando diferentes frameworks (AIDA, PAS, BAB)
- Selecionar a headline vencedora
- Escrever corpo do texto (máx 4 linhas, uma proposta de valor por linha)
- Criar CTA específico com verbo no imperativo + benefício
- Validar alinhamento copy ↔ imagem

### 3. Design do Criativo
- Carregar design system da marca
- Definir layout: posição da headline, corpo, CTA, imagem/visual
- Criar HTML/CSS auto-contido em 1080x1080
- Garantir legibilidade em 3 segundos (hierarquia visual)
- Incluir branding (@marlonlima.ia)

### 4. Revisão de Qualidade
- Avaliar copy contra critérios (clareza, especificidade, urgência, CTA)
- Avaliar design contra critérios (legibilidade, hierarquia, contraste, branding)
- Verificar alinhamento copy ↔ design
- Emitir veredito: APPROVE / REJECT com feedback acionável

### 5. Entrega
- Apresentar o criativo final ao usuário
- Fornecer arquivo HTML renderizável + screenshot
- Registrar aprendizados no squad memory

## Critérios de Decisão
- **Headline AIDA vs PAS**: Usar PAS quando o público é problem-aware. Usar AIDA quando é solution-aware ou product-aware.
- **Formato 1080x1080 vs 1080x1920**: Usar 1080x1080 para feed (default). Usar 1080x1920 quando o usuário especificar stories/reels.
- **Tom agressivo vs educacional**: Anúncios de oferta direta pedem urgência. Anúncios de awareness pedem educação.
