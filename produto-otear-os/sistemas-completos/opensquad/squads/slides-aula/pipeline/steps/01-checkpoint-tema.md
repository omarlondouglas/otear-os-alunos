# Checkpoint — Tema da Aula

Antes de começar a pesquisa, defina o tema da apresentação.

**Informações necessárias:**

1. **Tema da aula** — Sobre o que é a apresentação?
   (ex: "VS Code para iniciantes", "Como usar Git", "Introdução a APIs REST")

2. **Público-alvo** — Quem vai assistir?
   A. Iniciantes (nunca viram o assunto)
   B. Intermediários (já conhecem o básico)
   C. Avançados (querem aprofundar)

3. **Duração estimada** — Quantos slides aproximadamente?
   A. Curta (8-12 slides)
   B. Média (13-18 slides)
   C. Longa (19-25 slides)

4. **Estilo visual** — Alguma preferência?
   A. Padrão (dark com accent verde)
   B. Light (fundo claro)
   C. Misto (alternar)

Qual é o tema e as preferências para a aula?
