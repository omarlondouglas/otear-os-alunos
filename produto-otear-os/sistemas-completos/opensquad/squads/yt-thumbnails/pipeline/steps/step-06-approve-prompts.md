# Step 06: Aprovação dos Prompts

## Contexto
O Engenheiro de Prompts criou prompts otimizados para gerar sua thumbnail.

## Instruções
Apresente os prompts gerados (de `squads/yt-thumbnails/output/thumbnail-prompts.md`) ao usuário.

Para cada versão (Midjourney, DALL-E, Flux), mostre:
- O prompt completo
- As instruções de texto overlay

Mostre também as variações alternativas se existirem.

## Pergunta
Os prompts estão bons? Quer ajustar alguma coisa?

Opções:
1. Aprovar — prompts estão ótimos
2. Ajustar cores — quero mudar a palette
3. Ajustar composição — quero mudar o layout
4. Refazer — não ficou como imaginei
