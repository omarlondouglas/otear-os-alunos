# Step 04: Seleção de Conceito

## Contexto
O Diretor Criativo gerou conceitos de thumbnail para seu vídeo.

## Instruções
Apresente os conceitos gerados (de `squads/yt-thumbnails/output/thumbnail-concepts.md`) ao usuário.

Para cada conceito, mostre:
- Nome e fórmula
- Descrição visual resumida
- Cores e texto overlay
- Por que funciona

Destaque a recomendação do Diretor Criativo.

## Pergunta
Qual conceito você quer usar para a thumbnail?

Opções: lista numerada dos conceitos + "Nenhum, quero outro conceito"
