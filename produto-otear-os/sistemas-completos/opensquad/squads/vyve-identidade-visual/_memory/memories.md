# Squad Memory

- A identidade Vyve se apoia em "Vitalidade Contida": energia presente, elegante e sem excesso visual.
- O sistema visual deve fugir de estética hardcore de academia e se aproximar de rotina, wellness premium e praticidade diária.
- O primeiro volume da marca cobre tipografia, cores e bolha efervescente como elemento proprietário.
- A prancha de conceito deve começar apresentando a marca, para quem ela é e qual problema resolve; a bolha "3g" entra depois, como elemento gráfico do sistema.
- A essência visual aprovada é a logo com folhas formando um V, bolhas efervescentes acima e wordmark serifado VYVE; o deck deve explicar separadamente folhas, limão/água e fonte.
- A apresentação precisa ter exemplos concretos: mockups de potes de creatina com a logomarca e layouts de posts para feed, carrossel, stories e anúncios.
- Os exemplos de posts/social devem usar imagens geradas com GPT Image e ficar salvos em `output/assets`, com o HTML apenas exibindo e contextualizando esses assets.
- A abertura deve ser menos carregada: capa com H1/H2, depois uma página para "Para quem é", uma para "O que vende" e uma para "Como aparece", cada uma com imagem gerada que ilustra a mensagem.
