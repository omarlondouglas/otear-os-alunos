# Vyve Identidade Visual

Squad para criar e apresentar a identidade visual da Vyve em slides.

## Como rodar

```text
/opensquad run vyve-identidade-visual
```

## Output principal

- `output/brand-concept-slides.html`

## Assets visuais

- `output/assets/vyve-logo-concept.png` - conceito de logo com folhas e bolhas.
- `output/assets/vyve-packaging-mockup.png` - mockup de embalagem.
- `output/assets/vyve-concept-board.png` - prancha visual com paleta e elementos.
- `output/assets/vyve-audience-routine-ai.png` - imagem de rotina ativa para o slide "Para quem é".
- `output/assets/vyve-product-ritual-ai.png` - imagem anterior de produto/ritual.
- `output/assets/vyve-product-powder-ritual-ai.png` - imagem atual de produto em pó com dosador, água e limão fora do copo.
- `output/assets/vyve-lifestyle-routine-powder-ai.png` - fotografia de rotina com mulher preparando creatina em pó com dosador.
- `output/assets/vyve-physical-touchpoints-ai.png` - mockups físicos com pote, sachês, shaker, caixa e folheto.
- `output/assets/vyve-leaf-bubble-concept-ai.png` - imagem conceitual folha, bolha, limão e água.
- `output/assets/vyve-logo-leaf-symbol-ai.png` - imagem da folha da logo formando o V.
- `output/assets/vyve-post-produto-ai.png` - post de produto gerado com GPT Image.
- `output/assets/vyve-post-educativo-ai.png` - post educativo gerado com GPT Image.
- `output/assets/vyve-post-manifesto-ai.png` - post manifesto gerado com GPT Image.
- `output/assets/vyve-story-ad-ai.png` - story/anúncio vertical gerado com GPT Image.
- `output/assets/vyve-jar-limao-real-ai.png` - mockup real de pote claro/limão.
- `output/assets/vyve-jar-mint-real-ai.png` - mockup real de pote mint.
- `output/assets/vyve-jar-dark-real-ai.png` - mockup real de pote dark premium.

- `output/assets/vyve-carousel-02-ai.png` - post real de carrossel educativo, constância.

- `output/assets/vyve-logo-construction-ai.png` - estudo técnico raster da construção da logo.

## Diretriz de geração de imagens

- Gerar os assets visuais com GPT Image.
- Manter o HTML como camada de composição, legenda e explicação.
- Salvar os rasters finais em `output/assets` e referenciá-los diretamente no deck.
