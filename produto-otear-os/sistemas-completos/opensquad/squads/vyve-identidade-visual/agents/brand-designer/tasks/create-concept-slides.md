# Task: Create Brand Concept Slides

## Objective

Criar uma apresentação em HTML que explique o conceito da identidade visual
da Vyve para decisores internos e agências parceiras.

## Inputs

- Manual de identidade em `pipeline/data/brand-manual-v1.md`
- Conceito visual inicial fornecido pelo usuário

## Process

1. Extrair a narrativa central da marca.
2. Organizar a apresentação em slides com progressão clara:
   - capa apresentando a marca e sua promessa
   - público-alvo / para quem é, em página própria com imagem de rotina
   - o que vende, em página própria com imagem de produto/ritual
   - como aparece, em página própria com imagem de sistema visual
   - posicionamento
   - palavra-chave
   - conceito em imagens
   - por que as folhas formam o símbolo
   - por que limão e água traduzem o produto
   - por que a tipografia serifada premium sustenta a marca
   - território visual
   - tipografia
   - sistema de cores
   - variantes por sabor
   - bolha assinatura
   - aplicações
   - mockups de potes de creatina com a logomarca
   - exemplos de posts para feed, carrossel, stories e anúncios
   - regras rápidas para agências
3. Criar um HTML auto-contido com CSS próprio, usando Instrument Sans como fonte principal e Space Mono como fonte secundária para textos pequenos em estilo técnico/label.
4. Usar exclusivamente a paleta Green Screen oficial:
   - Green White #F4FFFC
   - Mint Fresh #91EAAF
   - Lime Energy #C3E956
   - Olive Screen #4D7111
   - Deep Green #1F4B2C
5. Manter o verde como identidade principal da marca; não introduzir paletas quentes externas.
6. Identificar claramente que o logotipo usa Cormorant Garamond 700 como base e deve ser refinado como vetor.
7. Identificar Space Mono como fonte de apoio para eyebrows, navegação, skip link, labels e textos pequenos técnicos.
8. Não abrir a apresentação com a bolha "3g"; esse elemento deve aparecer apenas depois que marca, público e posicionamento estiverem claros.
9. A prancha deve dissecar a essência visual em páginas separadas, explicando o motivo de cada elemento antes das regras finais.
10. Incluir exemplos visuais de aplicação, não apenas regras: pote claro, pote mint, pote dark premium, post produto, post educativo, manifesto, carrossel e story/anúncio.
11. Posts e stories devem usar imagens raster geradas com GPT Image quando o objetivo for mostrar criativos próximos de peças finais; usar HTML/CSS apenas para estrutura, legenda e explicação.
12. Evitar concentrar muitas informações no mesmo slide; cada página inicial deve defender apenas uma ideia.

## Output

`squads/vyve-identidade-visual/output/brand-concept-slides.html`
