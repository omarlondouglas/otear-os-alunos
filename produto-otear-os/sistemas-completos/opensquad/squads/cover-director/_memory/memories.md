# Cover Director — Memórias

## Preferências do Marlon
- Imagens de capa DEVEM ter rosto humano com expressão emocional intensa
- Olhar direto para câmera (eye contact)
- Expressões que ativam o sistema límbico: medo, dor, paixão, desespero, determinação
- NUNCA usar imagens genéricas sem emoção (mãos digitando, laptops, abstratos)
- Design system: fundo #0a0a0a, acento #A3F12E (verde neon), fonte Urbanist
- API de geração: Google Gemini (gemini-2.5-flash-image)
- Referência visual: @brandsdecoded__ no Instagram
