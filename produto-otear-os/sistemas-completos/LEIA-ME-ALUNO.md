# Motores internos do Otear OS

Esta pasta guarda os componentes tecnicos que ampliam o Otear OS. Para pedir ou usar uma capacidade, comece sempre pelo `produto-otear-os/nucleo-otear/roteador-otear.yaml`.

Os nomes das pastas tecnicas nao sao produtos separados. Eles funcionam como motores internos, governados pelo contrato, politica de modelos e regras de qualidade do Otear OS.

Os sistemas prontos de uso direto continuam em `../sistemas-prontos/`:

- `otear-prospeccao/`
- `otear-sites/`
- `otear-videos/`

Arquivos `.env.example` servem apenas como modelo de configuracao. Crie seu proprio `.env` quando um sistema solicitar chaves de API; ele nao e distribuido neste material.
