# Copy Quality Checklist

> Usado pelo Copy Reviewer para avaliar cada draft.

## Critérios Obrigatórios

### 1. Diagnóstico de Dor (mínimo 6/10)
- [ ] A copy nomeia uma dor ESPECÍFICA do lead (não genérica)
- [ ] O lead se reconheceria na dor descrita
- [ ] A dor é relevante para o público do briefing
- [ ] Não usa abertura genérica ("no cenário atual", "muitas pessoas")
- [ ] A dor aparece nos primeiros 20% da copy

### 2. Articulação de Benefício (mínimo 6/10)
- [ ] A copy apresenta BENEFÍCIO (transformação), não apenas FEATURE
- [ ] O benefício se conecta diretamente à dor diagnosticada
- [ ] O benefício é específico (números, prazos, resultados concretos)
- [ ] Cada feature é traduzida em "e daí?" para o lead
- [ ] O benefício principal é claro e não compete com benefícios secundários

### 3. Framework Identificável (mínimo 5/10)
- [ ] É possível identificar o copywriter/framework usado
- [ ] O framework é aplicado corretamente (não superficialmente)
- [ ] A estrutura da peça segue o padrão do mestre selecionado
- [ ] Técnicas específicas do mestre são visíveis no texto

### 4. Ausência de Tom Genérico de IA (mínimo 7/10)
- [ ] Sem clichês de IA ("nesse sentido", "é fundamental", "vale ressaltar")
- [ ] Sem vocabulário corporativo genérico ("potencialize", "alavanque")
- [ ] Tem personalidade e ritmo de copywriter (não de redação)
- [ ] Se trocar o produto por outro, a copy NÃO funcionaria (é específica)
- [ ] Frases curtas e impactantes, não parágrafos longos sem punch
- [ ] Sem emojis excessivos como substituto de copy real

## Critérios Complementares (não bloqueantes)

### Consistência com Briefing
- [ ] Produto correto
- [ ] Público correto
- [ ] Canal correto
- [ ] Tom alinhado (se especificado)
- [ ] Formato correto (se especificado)

### Qualidade Técnica
- [ ] CTA específico com benefício de clicar
- [ ] Hook forte na abertura
- [ ] Transições naturais entre seções
- [ ] Sem erros gramaticais
- [ ] Tamanho adequado para o formato

## Scoring

| Score | Classificação |
|-------|--------------|
| 9-10 | Excepcional — copy de mestre |
| 7-8 | Boa — pronta para uso |
| 5-6 | Adequada — funciona mas pode melhorar |
| 3-4 | Fraca — precisa de reescrita significativa |
| 1-2 | Inaceitável — rejeitar e refazer |
