# Mapa portátil do perfil Hermes

Este perfil é distribuído dentro de uma vault do Otear OS. Não use caminhos
absolutos nem os placeholders legados `{OTEAR_*}` para descobrir os sistemas.

Partindo da raiz da vault, use estes caminhos relativos:

```text
SOUL.md
MAPA DO OTEAR OS.md
produto-otear-os/nucleo-otear/CONTRATO-OPERACIONAL.md
produto-otear-os/nucleo-otear/roteador-otear.yaml
produto-otear-os/catalogo-integracao.json
.system/USER.md
.system/MEMORY.md
```

O perfil está em:

```text
produto-otear-os/sistemas-completos/hermes-profile-agenciasemesforco
```

Os outros motores ficam em `produto-otear-os/sistemas-completos` e os sistemas
de uso direto em `produto-otear-os/sistemas-prontos`. Antes de executar um
motor, consulte o catálogo para seus requisitos e a rota oficial no roteador.
