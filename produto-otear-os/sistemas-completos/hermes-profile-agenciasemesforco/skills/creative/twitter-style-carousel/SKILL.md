# Carrossel Twitter / X Style

Transforma raciocínios densos e insights rápidos em carrosséis com visual nativo do Twitter/X.

## Elementos de Design
- Layout estilo card de tweet: avatar circular, nome, `@handle`, ícone de verificado, texto do tweet, data/hora e métricas simuladas.
- Fundo: Dark mode (#000000 / #15202B) ou Branco (#FFFFFF).
- Texto: Máximo de 280 caracteres por slide para manter leitura dinâmica.

## Estrutura Recomendada
1. **Capa:** Tweet com frase controversa, dado surpreendente ou contraste ("A maioria acha X, mas a verdade é Y").
2. **Slides 2 a 6:** Desdobramento de cada ponto como se fossem respostas na mesma thread.
3. **Slide Final:** Resumo com CTA direto: *"Se esse post te ajudou, salve para consultar depois e comente sua opinião."*
