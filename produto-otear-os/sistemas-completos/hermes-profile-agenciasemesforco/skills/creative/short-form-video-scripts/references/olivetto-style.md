# Olivetto-style Short Video Pattern

Condensed from the user's `agi-agentes` examples such as `output/roteiro-4-niveis-consciencia-publico.md` and `output/roteiro-saas-vai-morrer.md`.

## Agent Framing

When available, treat `Olivetto` as the model for short marketing/video scripts: direct, viral but practical, using AIDA, levels of awareness, Golden Circle, concrete examples, and a comment CTA.

## Shape

A strong script usually includes:

- **Alternative hooks:** 3-7 options, all with tension or reframing.
- **Persona:** who is supposed to feel “this is for me”.
- **Angle:** one sentence explaining the core argument.
- **Trigger:** the emotional/cognitive lever, e.g. painful clarity, opportunity, mistake correction.
- **Timestamped 45-60s script:** short sections every 5-12 seconds.
- **On-screen editing:** text overlays, B-roll ideas, split screens, before/after frames.
- **Delivery notes:** tone, pauses, rhythm, irony, acceleration.
- **CTA:** specific comment prompt tied to the video idea.

## Useful Moves

- Start by attacking the wrong behavior: “Você está usando X errado.”
- Make the tool part of a larger workflow, not the entire point.
- Use “old way vs new way” to make the transformation obvious.
- Convert features into outcomes: video → fonte; fonte → insight; insight → roteiro/checklist/estratégia.
- End with a question that reveals use case intent: “Você usaria isso para estudar, criar conteúdo ou pesquisar concorrentes?”

## Browser Extension Caveat

For Chrome extension videos, add a short, non-alarmist note: check permissions before installing. Keep it brief unless the user explicitly asks for a security review.
