## Blended Formula

For a high-performing news script:

1. Open with tension like `dylan.page` or `gabrieladamuchi`.
2. Explain clearly like `gigaqian`.
3. Keep practical consequence visible like `rpn`.
4. Compress hard like `dr_cintas`.
5. Add future significance like `kanekallaway`.
6. Keep factual clarity like `v.daily.journal`.

## How To Use

When a user sends a news item:

1. identify the strongest angle
2. choose the primary trigger
3. choose the best creator archetype
4. write:
   - hook
   - development
   - screen/editing notes
   - delivery notes
   - closing
