## Padroes aprendidos

- Usuário prefere salvar carrossel para publicar manualmente no Instagram
- Imagens conceituais sem rostos humanos funcionaram bem (ampulheta com WhatsApp, portas com luz laranja)
- Dado âncora numérico na capa é a estratégia editorial mais forte (8x, 150%)
- Formato Storytelling funciona muito bem para temas de estratégia/caso real (arco narrativo completo)
- Formato Problema → Solução adequado para temas de automação/eficiência
- Conceito visual unificado por carrossel (uma metáfora que evolui) gera coesão visual forte
- Paleta com cor da marca mencionada na notícia (ex: laranja Anthropic) personaliza o design
- Modelo de imagem: gemini-2.5-flash-image (atualizado em 2026-03-30, modelo anterior expirou)
- Novo estilo de capa: Intaglio Engraving (personagem P&B) + elementos modernos coloridos (contexto)
- Rate limit do Gemini: esperar 5s entre chamadas para evitar erros de resposta vazia
