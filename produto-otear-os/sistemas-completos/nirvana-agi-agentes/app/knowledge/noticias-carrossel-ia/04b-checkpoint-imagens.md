# Checkpoint — Imagens para o Carrossel

Os slides em texto já estão prontos. O usuário pode visualizá-los na interface agora.

## Pergunta

Você quer adicionar imagens a algum slide?

1. **Sim — usar banco de imagens** (rápido, usa fotos do banco R2)
2. **Sim — gerar com IA** (mais lento, cria imagens exclusivas via Gemini)
3. **Não — manter só texto** (mais rápido, sem imagens)

Se escolher 1 ou 2: informe em quais slides você quer imagem (ex: "capa e slide 3") ou deixe em branco para o curador decidir os melhores slides.
