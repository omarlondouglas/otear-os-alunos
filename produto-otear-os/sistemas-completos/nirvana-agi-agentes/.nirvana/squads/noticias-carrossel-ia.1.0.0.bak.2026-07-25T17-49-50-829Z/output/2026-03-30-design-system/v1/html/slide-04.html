Design Tokens: a base de tudo.

Tokens são os valores primitivos do seu sistema. Eles definem as decisões visuais mais básicas que todo componente vai usar.

São variáveis, não valores fixos. Mude o token, muda tudo.

/* Cores */ --color-primary: #A3F12E; --color-bg: #0a0a0a; --color-text: #FFFFFF; /* Tipografia */ --font-family: 'Urbanist'; --font-size-h1: 64px; --font-size-body: 18px; /* Espaçamentos */ --space-sm: 8px; --space-md: 16px; --space-lg: 32px;
