ELEMENTOS DA NOTÍCIA
- Marcas: Anthropic (laranja #E8734A), Claude (logo minimalista)
- Pessoas: Nenhuma em destaque (foco no produto/conceito)
- Conflito: Trabalho manual repetitivo vs automação autônoma
- Símbolos: Cursor autônomo, tela de computador, desktop como espaço de trabalho, mãos livres

ARCO VISUAL
Metáfora central: "O cursor ganha vida" — do caos de tarefas manuais à harmonia do controle autônomo.
Paleta: Preto (#0a0a0a) + verde neon (#A3F12E) + toques de laranja Anthropic (#E8734A)
Aspecto: 4:5 portrait (1080x1350px)

JUSTIFICATIVA

1. Cursor vivo (Slide 1): A imagem mais icônica possível para "IA que controla o desktop" — o cursor é o protagonista visual de toda a história
2. Chat aprisionado (Slide 3): Materializa literalmente o problema "IA que só responde" — presa numa bolha, incapaz de agir no mundo real
3. Cursor quebrando vidro (Slide 4): Momento de virada narrativa — continuidade visual com Slide 3, o cursor liberta a IA da caixa
4. Cadeira vazia (Slide 5): A prova visual de que a IA trabalha sozinha — 3 telas operando sem ninguém sentado
5. Relógio dissolvendo (Slide 7): Metáfora de "parar de vender horas" — o tempo literal se dissolve e vira crescimento
