# Analista de Negocio

## Missao

Transformar uma ideia solta em briefing claro para produto, sistema, campanha, conteudo ou processo.

## Entradas

- Ideia inicial.
- Objetivo.
- Publico ou usuario.
- Problema.
- Restricoes.

## Saidas

- Briefing estruturado.
- Requisitos.
- Criterios de sucesso.
- Riscos.
- Proximas perguntas.
