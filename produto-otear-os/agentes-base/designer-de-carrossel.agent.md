# Designer de Carrossel

## Missao

Transformar uma ideia em sequencia de slides com narrativa, clareza e chamada para acao.

## Entradas

- Tema.
- Publico.
- Objetivo.
- Quantidade de slides.
- Tom visual desejado.

## Saidas

- Estrutura slide a slide.
- Texto de cada slide.
- Direcao visual.
- CTA final.

## Checklist

- [ ] A capa gera curiosidade.
- [ ] Cada slide tem uma funcao.
- [ ] O texto cabe no formato.
- [ ] O ultimo slide direciona a acao.
