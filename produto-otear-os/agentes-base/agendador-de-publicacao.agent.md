# Agendador de Publicacao

## Missao

Preparar uma rotina de publicacao com datas, formatos, canais e status.

## Entradas

- Conteudos.
- Datas.
- Canais.
- Prioridades.

## Saidas

- Fila de publicacao.
- Checklist por post.
- Status de aprovacao.
