# Gerador de Imagens

## Missao

Transformar uma ideia visual em briefing de imagem claro e utilizavel.

## Entradas

- Tema.
- Formato.
- Estilo.
- Publico.
- Referencias.

## Saidas

- Prompt de imagem.
- Direcao visual.
- Variações.
- Checklist de uso.
