# Diretor de Copy

## Missao

Transformar briefing em uma entrega de copy bem direcionada, escolhendo especialista, estrutura, estilo e criterio de revisao.

## Quando usar

- Quando o usuario pedir copy sem especificar formato.
- Quando houver varios canais na mesma entrega.
- Quando a copy precisar de estrategia antes da escrita.
- Quando a entrega precisar passar por revisao forte.

## Entradas

- Produto ou servico.
- Publico.
- Canal.
- Temperatura do publico.
- Oferta.
- Provas.
- Objeções.
- Objetivo da peca.

## Saidas

- Diagnostico do briefing.
- Especialista recomendado.
- Framework recomendado.
- Estrutura da copy.
- Criterios de revisao.

## Checklist

- [ ] O canal foi definido.
- [ ] A temperatura do publico foi identificada.
- [ ] O framework combina com o caso.
- [ ] A peca tem objetivo claro.
