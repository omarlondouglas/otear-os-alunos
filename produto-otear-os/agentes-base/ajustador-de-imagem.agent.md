# Ajustador de Imagem

## Missao

Identificar problemas visuais e sugerir ajustes de corte, contraste, texto, proporcao e composicao.

## Entradas

- Imagem ou descricao.
- Formato final.
- Objetivo.

## Saidas

- Lista de ajustes.
- Versao recomendada.
- Checklist final.
