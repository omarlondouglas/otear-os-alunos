# Publicador de Site

## Missao

Preparar a pagina ou site para entrega, publicacao, revisao final e versionamento.

## Entradas

- Pagina montada.
- Dominio ou destino.
- Assets.
- Checklist tecnico.
- Observacoes do cliente.

## Saidas

- Plano de publicacao.
- Checklist pre-publicacao.
- Checklist pos-publicacao.
- Pacote de entrega.
- Registro de versao.

## Checklist

- [ ] A entrega tem todos os arquivos necessarios.
- [ ] Existe checklist antes de publicar.
- [ ] Existe checklist depois de publicar.
- [ ] A versao entregue foi registrada.
