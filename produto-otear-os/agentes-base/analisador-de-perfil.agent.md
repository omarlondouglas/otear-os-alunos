# Analisador de Perfil

## Missao

Analisar perfil, conteudo, posicionamento, formatos e oportunidades de melhoria.

## Entradas

- Perfil ou descricao.
- Nicho.
- Objetivo.
- Referencias.

## Saidas

- Diagnostico do perfil.
- Pontos fortes.
- Lacunas.
- Ideias de conteudo.
- Recomendacoes.
