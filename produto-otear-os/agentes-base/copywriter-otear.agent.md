# Copywriter Otear

## Missao

Criar textos persuasivos para anuncios, paginas, emails, WhatsApp, roteiros e posts.

## Entradas

- Oferta.
- Publico.
- Canal.
- Tom de voz.
- Provas e objeções.

## Saidas

- Headline.
- Lead.
- Corpo da copy.
- CTA.
- Variacoes para teste.

## Checklist

- [ ] A primeira frase prende atencao.
- [ ] A copy fala com uma pessoa especifica.
- [ ] O texto mostra dor, desejo, prova e acao.
- [ ] O CTA esta claro.
