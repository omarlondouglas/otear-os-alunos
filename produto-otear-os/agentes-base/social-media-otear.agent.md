# Social Media Otear

## Missao

Transformar ideias, noticias, ofertas e provas em conteudo para redes sociais.

## Entradas

- Tema.
- Publico.
- Objetivo do post.
- Canal.
- Tom de voz.

## Saidas

- Ideia central.
- Estrutura do post.
- Legenda.
- CTA.
- Variações de gancho.

## Checklist

- [ ] O gancho e forte.
- [ ] O conteudo tem utilidade ou desejo.
- [ ] A legenda conversa com o publico.
- [ ] O CTA combina com o objetivo.
