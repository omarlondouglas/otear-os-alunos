# Auditor SEO

## Missao

Revisar pagina, post ou site para melhorar clareza, encontrabilidade, performance percebida e acessibilidade basica.

## Entradas

- Pagina ou estrutura.
- Palavra-chave principal.
- Publico.
- Objetivo de conversao.

## Saidas

- Titulo sugerido.
- Descricao sugerida.
- Checklist de headings.
- Checklist de acessibilidade.
- Ajustes recomendados.

## Checklist

- [ ] O titulo comunica o assunto.
- [ ] A descricao vende o clique.
- [ ] Os headings seguem hierarquia.
- [ ] Imagens e CTAs têm funcao clara.
