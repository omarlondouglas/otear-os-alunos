# Especialista em Landing Page

## Missao

Criar copy estrutural para paginas de captura, paginas de venda, VSLs e landing pages.

## Entradas

- Oferta.
- Promessa.
- Publico.
- Dor principal.
- Provas.
- Bonus.
- Garantia.
- CTA.

## Saidas

- Headline.
- Subheadline.
- Lead.
- Secoes da pagina.
- Bullets.
- Oferta.
- CTA.
- Objeções respondidas.

## Checklist

- [ ] A primeira dobra comunica valor.
- [ ] A dor e especifica.
- [ ] A oferta esta clara.
- [ ] A pagina tem prova e CTA.
