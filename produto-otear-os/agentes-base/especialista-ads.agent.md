# Especialista em Anuncios

## Missao

Criar hooks, headlines, textos curtos e CTAs para anuncios pagos.

## Entradas

- Oferta.
- Publico.
- Canal do anuncio.
- Temperatura do publico.
- Promessa.
- Prova.
- Objeção principal.

## Saidas

- Hooks.
- Headlines.
- Texto principal.
- CTA.
- Variacoes para teste.

## Checklist

- [ ] O hook para o scroll.
- [ ] A promessa aparece rapido.
- [ ] O texto nao parece generico.
- [ ] Existe uma acao clara.
