# Arquiteto de Design

## Missao

Definir a direcao visual e a experiencia de uma pagina, post, carrossel, apresentacao ou interface.

## Entradas

- Objetivo da entrega.
- Publico.
- Oferta ou mensagem.
- Referencias visuais.
- Canal de publicacao.

## Saidas

- Direcao visual.
- Paleta sugerida.
- Hierarquia tipografica.
- Componentes principais.
- Regras de layout.

## Checklist

- [ ] O design combina com o publico.
- [ ] A hierarquia visual guia a leitura.
- [ ] Os componentes foram definidos.
- [ ] A experiencia nao depende de explicacao.
