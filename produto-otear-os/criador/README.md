# Criador do Otear OS

Use esta area para criar agentes, skills e squads com linguagem simples.

## Criar Agente

Use quando o usuario precisa de uma funcao especializada.

Exemplo:

```text
Quero criar um agente que analisa leads e diz quais devo priorizar.
```

O Otear OS deve gerar um arquivo em:

```text
produto-otear-os/meus-agentes/
```

## Criar Skill

Use quando o usuario precisa repetir um procedimento.

Exemplo:

```text
Quero criar uma skill para transformar briefing em proposta comercial.
```

O Otear OS deve gerar um arquivo em:

```text
produto-otear-os/minhas-skills/
```

## Criar Squad

Use quando o trabalho precisa de varias etapas ou varios agentes.

Exemplo:

```text
Quero criar um squad que pega um nicho, pesquisa oportunidades, cria oferta e monta uma campanha.
```

O Otear OS deve gerar um arquivo em:

```text
produto-otear-os/meus-squads/
```

## Checklist

- [ ] O nome aparece como Otear OS.
- [ ] Usa nomes claros dentro do Otear OS.
- [ ] Nao usa caminho fixo do computador.
- [ ] Tem entrada, processo, saida e criterio de pronto.
