# Checklist de Qualidade de Copy

## Dor

- [ ] A copy nomeia uma dor especifica.
- [ ] O lead se reconhece na dor.
- [ ] A dor aparece cedo.
- [ ] A abertura nao e generica.

## Beneficio

- [ ] A copy vende transformacao, nao apenas recurso.
- [ ] O beneficio se conecta com a dor.
- [ ] O beneficio e concreto.
- [ ] Cada recurso responde "e dai?".

## Estrutura

- [ ] Existe um framework claro.
- [ ] A estrutura combina com o canal.
- [ ] O texto tem progressao.
- [ ] O CTA aparece no momento certo.

## Anti-Generico

- [ ] Nao usa frases vazias.
- [ ] Nao usa tom corporativo sem vida.
- [ ] Tem ritmo de copy, nao de redacao.
- [ ] Se trocar o produto, o texto perde sentido.

## Canal

- [ ] O tamanho combina com o formato.
- [ ] O gancho combina com a plataforma.
- [ ] A promessa esta clara.
- [ ] A acao final e simples.
