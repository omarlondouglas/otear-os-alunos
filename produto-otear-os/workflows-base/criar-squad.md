# Workflow - Criar Squad no Otear OS

1. Definir resultado final.
2. Quebrar em etapas.
3. Escolher agentes base ou agentes do usuario.
4. Organizar handoffs.
5. Definir criterios de aceite.
6. Salvar em `produto-otear-os/meus-squads`.
