# Workflow - Criar Agente no Otear OS

1. Receber pedido do usuario.
2. Identificar qual funcao especializada ele precisa.
3. Preencher contrato de agente.
4. Criar checklist de qualidade.
5. Salvar em `produto-otear-os/meus-agentes`.
6. Mostrar como chamar o agente no cockpit.
