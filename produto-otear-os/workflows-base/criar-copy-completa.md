# Workflow - Criar Copy Completa no Otear OS

1. Receber briefing.
2. Validar produto, publico, oferta, canal e CTA.
3. Identificar temperatura do publico.
4. Escolher framework de copy.
5. Escolher especialista do canal.
6. Gerar primeira versao.
7. Revisar com checklist de qualidade.
8. Criar variações para teste.
9. Entregar copy final com explicacao curta da estrategia.
