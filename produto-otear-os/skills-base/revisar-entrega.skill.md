# Revisar Entrega

## Procedimento

1. Comparar entrega com pedido original.
2. Verificar se faltou alguma parte.
3. Remover excesso tecnico.
4. Melhorar clareza.
5. Confirmar proxima acao.

## Saida

Entrega revisada e pronta para uso.
