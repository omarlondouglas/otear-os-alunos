# Criar Campanha

## Procedimento

1. Definir oferta e publico.
2. Criar promessa central.
3. Criar angulos de comunicacao.
4. Criar anuncio, post, mensagem e CTA.
5. Revisar objeções.
6. Entregar campanha organizada.

## Saida

Campanha com copy, canais sugeridos e proximas acoes.
