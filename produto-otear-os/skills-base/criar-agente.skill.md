# Criar Agente

## Procedimento

1. Perguntar qual resultado o agente deve produzir.
2. Definir publico, entradas e saidas.
3. Escrever missao em uma frase.
4. Definir ferramentas permitidas.
5. Criar checklist de qualidade.
6. Salvar em `produto-otear-os/meus-agentes`.

## Saida

Um arquivo `.agent.md` pronto para uso.
