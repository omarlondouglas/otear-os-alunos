# Criar Copy

## Procedimento

1. Entender produto, publico, canal e objetivo.
2. Identificar temperatura do publico.
3. Escolher especialista de canal.
4. Escolher framework de copy.
5. Criar primeira versao.
6. Revisar com checklist de qualidade.
7. Entregar versao final e variações.

## Saida

Copy pronta para uso, com CTA, variações e explicacao curta da estrategia.
