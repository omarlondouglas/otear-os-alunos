# Criar Skill

## Procedimento

1. Identificar o procedimento.
2. Definir quando a skill deve ser usada.
3. Listar entradas necessarias.
4. Escrever passo a passo.
5. Definir saida esperada.
6. Criar checklist de pronto.
7. Salvar em `produto-otear-os/minhas-skills`.

## Saida

Um arquivo `.skill.md` reutilizavel.
