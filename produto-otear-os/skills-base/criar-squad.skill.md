# Criar Squad

## Procedimento

1. Definir o resultado final.
2. Quebrar o trabalho em etapas.
3. Escolher ou criar agentes para cada etapa.
4. Definir ordem do workflow.
5. Definir criterios de aceite.
6. Salvar em `produto-otear-os/meus-squads`.

## Saida

Um squad pronto para operar no Otear OS.
