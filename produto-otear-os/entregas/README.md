# Entregas do aluno

O Hermes salva aqui resultados criados pelas skills de sistemas do Otear OS.
Crie uma subpasta pelo nome do sistema e use nomes claros, por exemplo
`sites/landing-academia.md` ou `copy/campanha-outubro.md`.

Nunca salve chaves, tokens, dados pessoais de terceiros ou exportações confidenciais
nesta pasta.
