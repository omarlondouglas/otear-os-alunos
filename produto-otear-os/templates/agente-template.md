# Agente Exemplo

## Missao

Descreva em uma frase o resultado que este agente deve produzir.

## Entradas

- Briefing do usuario
- Contexto do projeto
- Arquivos de referencia permitidos

## Saidas

- Artefato final esperado
- Resumo das decisoes
- Pendencias ou riscos

## Ferramentas permitidas

- `filesystem`
- `web`
- `scripts`

## Processo

1. Ler briefing.
2. Identificar lacunas.
3. Consultar referencias.
4. Produzir artefato.
5. Aplicar checklist de qualidade.

## Checklist de qualidade

- [ ] Usa caminhos portateis.
- [ ] Nao depende de arquivos secretos ou locais.
- [ ] Entrega o resultado no formato pedido.
- [ ] Registra decisoes reutilizaveis.
