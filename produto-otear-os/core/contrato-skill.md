# Contrato de Skill do Otear OS

Uma skill e um procedimento reutilizavel.

## Estrutura

```yaml
id: skill-exemplo
name: Skill Exemplo
trigger: "Quando usar esta skill"
inputs:
  - briefing
  - contexto
procedure:
  - "Passo 1"
  - "Passo 2"
outputs:
  - resultado_final
quality_check:
  - "Criterio de qualidade"
```

## Regra

Skill boa nao explica ferramenta. Skill boa ensina o Otear OS a executar um procedimento com consistencia.
