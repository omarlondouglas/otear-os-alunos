# Como Abrir no Obsidian

## Passo 1

Baixe e extraia a pasta:

```text
otear-os-aluno
```

Coloque em um lugar fácil, por exemplo:

```text
Documentos/Otear OS
Downloads/Otear OS
Google Drive/Otear OS
OneDrive/Otear OS
```

## Passo 2

Abra o Obsidian.

Escolha:

```text
Open folder as vault
```

ou, em português:

```text
Abrir pasta como cofre/vault
```

## Passo 3

Selecione a pasta:

```text
otear-os-aluno
```

## Passo 4

Abra o arquivo:

```text
START AQUI.md
```

ou:

```text
00-COMECE-AQUI/00 - Leia Primeiro.md
```

## Se Não Aparecer Bonito

Use a busca do Obsidian e procure:

```text
START AQUI
```

ou:

```text
MAPA DO OTEAR OS
```
