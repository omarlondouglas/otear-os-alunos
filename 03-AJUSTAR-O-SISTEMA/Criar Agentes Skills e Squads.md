# Criar Agentes Skills e Squads

## Criar Agente

Use quando precisar de uma funcao especializada.

Exemplo:

```text
Otear OS, crie um agente para responder leads de clinica estetica.
```

Salve em:

```text
produto-otear-os/meus-agentes
```

## Criar Skill

Use quando precisar repetir um procedimento.

Exemplo:

```text
Otear OS, transforme meu processo de atendimento em uma skill.
```

Salve em:

```text
produto-otear-os/minhas-skills
```

## Criar Squad

Use quando a entrega tiver varias etapas.

Exemplo:

```text
Otear OS, crie um squad para captar leads, qualificar e mandar proposta.
```

Salve em:

```text
produto-otear-os/meus-squads
```
